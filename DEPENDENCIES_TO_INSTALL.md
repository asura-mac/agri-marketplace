# Required Dependencies for i18n Feature

## NPM Packages to Install

Run the following command to install the required dependencies for internationalization:

```bash
npm install react-i18next i18next i18next-browser-languagedetector
```

## Package Details

### react-i18next
- **Version**: Latest stable
- **Purpose**: React integration for i18next internationalization framework
- **Usage**: Provides useTranslation hook and translation components

### i18next
- **Version**: Latest stable  
- **Purpose**: Core internationalization framework
- **Usage**: Manages translations, language switching, and interpolation

### i18next-browser-languagedetector
- **Version**: Latest stable
- **Purpose**: Automatically detects user language preferences
- **Usage**: Detects language from localStorage, navigator, and other browser sources

## Installation Command

```bash
cd agrimarket
npm install react-i18next i18next i18next-browser-languagedetector
```

These packages are required for the language translation feature to work properly.
